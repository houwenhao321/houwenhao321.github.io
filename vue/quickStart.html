快速上手 ​

1. 下载并安装node ​

  • node下载地址：node
  • 打开电脑上的应用商店，搜索node，点击安装
  • 安装nvm：nvm，然后使用nvm安装node nvm安装使用步骤
  • 安装完成后，打开命令行工具，输入node -v和npm -v，如果能够显示版本号，则说明安装成功。

2. 安装vue cli ​

  1. 安装vue cli：npm install -g @vue/cli
  2. 安装完成后，输入vue -V，如果能够显示版本号，则说明安装成功。

3. 创建vue项目 ​

确保你安装了最新版本的 Node.js，并且你的当前工作目录正是打算创建项目的目录。在命令行中运行以下命令 (不要带上 $ 符号)：

  • npm
sh
npm create vue@latest
  • pnpm
sh
pnpm create vue@latest
  • yarn
sh
# For Yarn (v1+)
yarn create vue

# For Yarn Modern (v2+)
yarn create vue@latest
 
# For Yarn ^v4.11
yarn dlx create-vue@latest
  • bun
sh
bun create vue@latest

这一指令将会安装并执行 create-vue，它是 Vue 官方的项目脚手架工具。你将会看到一些诸如 TypeScript 和测试支持之类的可选功能提示：

sh
✔ Project name: … <your-project-name>
✔ Add TypeScript? … No / Yes
✔ Add JSX Support? … No / Yes
✔ Add Vue Router for Single Page Application development? … No / Yes
✔ Add Pinia for state management? … No / Yes
✔ Add Vitest for Unit testing? … No / Yes
✔ Add an End-to-End Testing Solution? … No / Cypress / Nightwatch / Playwright
✔ Add ESLint for code quality? … No / Yes
✔ Add Prettier for code formatting? … No / Yes
✔ Add Vue DevTools 7 extension for debugging? (experimental) … No / Yes

Scaffolding project in ./<your-project-name>...
Done.

如果不确定是否要开启某个功能，你可以直接按下回车键选择 No。在项目被创建后，通过以下步骤安装依赖并启动开发服务器：

  • npm
sh
cd <your-project-name>
npm install
npm run dev
  • pnpm
sh
cd <your-project-name>
pnpm install
pnpm run dev
  • yarn
sh
cd <your-project-name>
yarn
yarn dev
  • bun
sh
cd <your-project-name>
bun install
bun run dev

当你准备将应用发布到生产环境时，请运行：

sh
npm run build
  • pnpm
sh
pnpm run build
  • yarn
sh
yarn build
  • bun
sh
bun run build

此命令会在 ./dist 文件夹中为你的应用创建一个生产环境的构建版本。关于将应用上线生产环境的更多内容，请阅读生产环境部署指南。
